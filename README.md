# WebSSH Client

A professional, clean, and user-friendly web-based SSH terminal client for modern browsers.

## Features

- **Real-time Terminal**: Fast, responsive terminal interface built for efficiency.
- **SSH Support**: Connect securely to remote servers via SSH (Password, Private Key, TOTP, Passphrase).
- **Multi-Tab Support**: Manage multiple sessions or local terminal instances in a clean tabbed interface.
- **Responsive UI**: Optimized for both desktop and mobile use.
- **Official Icons**: Uses official, high-fidelity vector icons for all operating systems.
- **No Extra Dependencies**: Lightweight and focused performance.

## Usage

1. Open the application in your browser.
2. For local terminal, click the "ttyd" button.
3. For remote SSH, enter the host information and select your preferred authentication method.
4. Use long-press or right-click to access context menu (Copy, Paste, Select All, Clear).
5. Use pinch-to-zoom or Ctrl+Wheel to adjust text size without affecting layout.
